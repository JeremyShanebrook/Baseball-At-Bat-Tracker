# Beta.16 — Home menu + top card buttons

## Sidebar

The "My Player" menu entry is now called "Home". It opens the same
page.

## Top card

The card at the top of that page no longer says "My Players". It is
just the game buttons: Start a Game (or Start Another Game while a
game is active) plus Resume Active Game when a game is active. No
toggle, just the buttons.

The My Players profiles section below it is unchanged.

## Version

versionCode 21 / 1.3.1-beta.16. No other changes.
